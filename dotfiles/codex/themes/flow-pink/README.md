# Flow Pink

Flow Pink matches the local themes used by:

- Ghostty: `~/.config/ghostty/themes/flow-pink`
- Herdr: `~/.config/herdr/config.toml`
- Neovim: [`0xstepit/flow.nvim`](https://github.com/0xstepit/flow.nvim)

The dark palette follows the active local Flow configuration. The light
palette is generated from `flow.nvim`'s default light variant.

| Role | Dark | Light |
| --- | --- | --- |
| Background | `#1b2328` | `#d7dfe4` |
| Foreground | `#5e7b8d` | `#728fa1` |
| Accent | `#ff007b` | `#ff007b` |
| Added | `#79db70` | `#66ba5e` |
| Removed | `#db7079` | `#ba5e66` |
| Code font | Monaspace Argon | Monaspace Argon |
| Bundled code theme | Night Owl | One Light |

Both variants use opaque windows and a contrast value of 50.

Use [`dark.txt`](dark.txt) and [`light.txt`](light.txt) with the matching
import controls in **Codex > Settings > Appearance**.
