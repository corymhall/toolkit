*herdr-nvim.txt*  Open Pi file links in a neighboring Herdr Neovim pane

==============================================================================

==============================================================================
1. Overview                                            *herdr-nvim-overview*

herdr-nvim starts a Neovim RPC server when Neovim runs inside Herdr and reports
that address as pane metadata. The toolkit's Pi extension and macOS URL handler
use the metadata to open a clicked file in the Neovim pane immediately to the
right of Pi.

The runtime can be installed as a native package by:
>
    extensions/pi-ui/herdr-nvim-links/install.sh
<
or declared as an eager local plugin in a package manager. No setup call,
command, or key mapping is required.

==============================================================================
2. Requirements                                    *herdr-nvim-requirements*

- macOS and Ghostty with OSC 8 hyperlink support
- Herdr available as `herdr` on Neovim's PATH
- Neovim 0.10 or newer with |vim.system()| and |serverstart()|
- Pi running inside a Herdr-managed pane

==============================================================================
3. Behavior                                            *herdr-nvim-behavior*

At startup, the plugin:

1. Does nothing outside Herdr.
2. Reuses |v:servername| or starts a local RPC server.
3. Reports `nvim_server=<address>` through `herdr pane report-metadata`.

Setup is idempotent. Failures are reported with |vim.notify()| and do not stop
Neovim startup.
